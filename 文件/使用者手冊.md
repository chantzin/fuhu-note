# FUHU-NOTE 筆記 — 使用者手冊

> 版本：v1.1（MVP）｜ 更新日期：2026-10-05 ｜ 專案位置：`D:\FUHU-NOTE`

## 1. FUHU-NOTE 是什麼

FUHU-NOTE 是類似 Evernote 的跨平台筆記 App，特色：

| 特色 | 說明 |
| --- | --- |
| 離線優先 | 斷網也能完整閱讀、編輯、新增筆記，恢復連線後自動同步 |
| 跨平台 | Windows／macOS／Linux 瀏覽器皆可執行；安卓手機可安裝為 App（PWA） |
| Google 帳號同步 | 手機與電腦登入同一 Google 帳號，筆記即時同步（需先完成 Firebase 設定） |
| 完整分類 | 筆記本、標籤、全文搜尋、垃圾桶 |

## 2. 快速開始（Windows 本機執行）

1. 雙擊 `D:\FUHU-NOTE\安裝程式\啟動FUHU-NOTE本機版.bat`
2. 瀏覽器自動開啟 `http://127.0.0.1:8000`
3. 開始記筆記（此階段為**本機模式**，資料存於瀏覽器本地）

> 關閉黑色命令視窗即停止服務。資料不會因關閉服務而遺失（存於瀏覽器 IndexedDB）。

## 3. 主要功能

### 3.1 筆記
- **新增**：右上角「新增筆記」，輸入標題與內文（自動儲存，無需手動按儲存）。
- **編輯**：工具列提供粗體、斜體、底線、刪除線、H2/H3 標題、項目符號、編號清單、待辦清單、連結、插入圖片。
- **自動儲存**：停止輸入 0.8 秒後自動儲存；編輯器右上角顯示「已儲存／儲存中」。

### 3.2 筆記本
- 左側「＋」建立新筆記本；滑鼠移到筆記本名稱上出現「重新命名／刪除」。
- 刪除筆記本時，其中的筆記會移入「未分類」並保留。

### 3.3 標籤
- 編輯筆記時，於內文上方「＋ 標籤」加入標籤；點標籤可移除。
- 側欄「標籤」區可依標籤篩選。

### 3.4 搜尋
- 頂端搜尋框即時篩選筆記（標題＋內文）。

### 3.5 垃圾桶
- 筆記刪除後先進入垃圾桶，可還原或永久刪除。

### 3.6 備份
- 右上角「匯出備份」→ 下載 JSON 備份檔，建議存入 `D:\FUHU-NOTE\備份`。
- 「設定 → 匯入備份」可將備份檔匯回（會取代本機現有資料）。

## 4. Google 帳號登入與跨裝置同步

1. 先完成《Firebase設定指南.md》的設定（建立 Firebase 專案並將設定貼入 `js\config.js`）。
2. 重新整理頁面，側欄底部出現「使用 Google 帳號登入」。
3. 登入後，狀態列顯示「已同步」。
4. 在其他裝置（手機／另一台電腦）開啟同一網址並登入同一帳號，筆記即自動同步。

同步原則：
- 衝突以「最後寫入勝出」處理，且以**欄位**為單位（A 改標題、B 改內文，兩者都保留）。
- 離線期間的編輯會暫存於本機佇列，恢復連線後自動上傳。

## 5. 安裝到安卓手機

**方式 A（推薦）— 網頁 App（PWA）**
1. 將 App 部署到 Firebase Hosting 或自有 HTTPS 伺服器（見《Firebase設定指南.md》第 7 節）。
2. 手機 Chrome 開啟該網址。
3. 瀏覽器選單 →「加到主畫面」→ 完成後手機桌面出現 FUHU-NOTE 圖示，點開即如一般 App 全螢幕使用（含離線）。

**方式 B — 區域網路測試（僅測試用）**
1. 電腦與手機連同一 Wi-Fi。
2. 以 `python -m http.server 8000` 啟動（或使用啟動.bat），手機瀏覽器開啟 `http://<電腦IP>:8000`。
3. 注意：區域網路 IP 非 HTTPS，PWA 安裝與 Service Worker 可能受限；正式使用請走方式 A。

**方式 C — 原生 APK（後續階段）**
- 可再以 Capacitor 將本 PWA 包裝為安卓 APK 安裝檔（需 Android Studio），屆時可提供安裝檔放入 `安裝程式` 資料夾。

## 6. 資料存放位置說明

| 資料 | 位置 |
| --- | --- |
| 筆記本機快取 | 瀏覽器 IndexedDB（本機） |
| 雲端同步資料 | Firebase Firestore／Storage（設定後） |
| 手動備份檔 | `D:\FUHU-NOTE\備份`（建議） |
| 專案原始碼 | `D:\FUHU-NOTE\程式\fuhu-note` |

## 7. 常見問題

**Q：狀態列顯示「本機模式」？**
尚未設定 Firebase（或未登入）。資料只在本機，完成設定指南後即可同步。

**Q：登入時跳出「授權網域」錯誤？**
在 Firebase 主控台 Authentication → 設定 → 已授權網域，加入你使用的網址（本機 `localhost`／`127.0.0.1` 預設已含；正式網址需新增）。

**Q：換瀏覽器／清掉瀏覽器資料後筆記不見了？**
本機模式資料存在瀏覽器內，清除瀏覽器資料會一併刪除。請務必定期「匯出備份」；設定 Firebase 後，重新登入即可從雲端同步回來。

**Q：圖片在雲端模式上傳失敗？**
會自動改以「本機圖片」方式內嵌（資料體積較大），並顯示提示。
