備份

建議將備份檔存入 D:\FUHU-NOTE\備份 資料夾。
匯入支援：FUHU-NOTE 備份（.json）／Joplin 匯出（.md，可選多檔）／Evernote 匯出（.enex）。
Joplin：匯出時選「Markdown 資料夾」；Evernote：匯出時選「.enex」。

外觀

深色模式會在夜間或暗處使用時減輕眼睛負擔。

筆記本排序

設定側邊欄「筆記本」區的排列方式。

附件

列出所有筆記中的圖片與檔案附件，方便查找與整理。

Web 剪藏

在電腦瀏覽器把網頁存成筆記：
1. 將下面整段文字加入書籤列（書籤管理員 → 新增書籤 → 名稱「剪藏到 FUHU-NOTE」、網址貼上此段）；
2. 瀏覽任何網頁時，點這個書籤，就會把網頁標題、網址與選取文字存入 FUHU-NOTE。
