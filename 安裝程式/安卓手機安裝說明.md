# 安卓手機安裝說明

FUHU-NOTE 採用漸進式網頁應用（PWA）技術：**不需上架 Google Play，也能安裝到安卓手機當一般 App 使用**（桌面圖示、全螢幕、離線可用）。

## 方式 A（推薦）— 安裝已部署的網頁 App

**前置**：先完成《Firebase設定指南.md》並部署上線，取得正式網址（如 `https://專案名.web.app`）。

1. 手機開啟 **Chrome**，輸入網址。
2. 首次開啟時，Chrome 可能自動跳出「加入主畫面」；若無，依下一步手動操作。
3. 點 Chrome 右上角「⋮」選單 → **加到主畫面**（或「安裝應用程式」）。
4. 手機桌面出現 FUHU-NOTE 圖示 → 點開即全螢幕 App 使用（含離線編輯）。
5. 登入 Google 帳號後，即與電腦同步。

## 方式 B — 區域網路測試（僅開發測試用）

1. 電腦與手機連同一 Wi-Fi。
2. 電腦執行 `D:\FUHU-NOTE\安裝程式\啟動FUHU-NOTE本機版.bat`。
3. 手機 Chrome 開啟 `http://<電腦IP>:8000`（電腦 IP 可用 `ipconfig` 查詢）。
4. 注意：非 HTTPS 環境下，PWA 安裝與 Service Worker 可能受限，僅供開發預覽；正式使用請用方式 A。

## 方式 C — 原生 APK（後續階段）

若需要「直接安裝的 .apk 檔」，後續可將本 PWA 用 **Capacitor** 包裝為安卓原生專案：

```bat
cd D:\FUHU-NOTE\程式\fuhu-note
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init FUHU-NOTE com.fuhunote.app --web-dir=.
npx cap add android
npx cap sync
```

接著用 **Android Studio** 開啟 `android` 資料夾 → Build → 產生 APK／AAB（需安裝 Android Studio；屆時可代為操作，安裝檔產出後放回 `D:\FUHU-NOTE\安裝程式`）。

## 安裝後注意

- PWA 離線快取由 Service Worker 管理；每次更新版本後，重新整理頁面即自動更新。
- 手機與電腦同步以 **Google 帳號**為錨點：兩端登入同一帳號即同步。
