# FUHU-NOTE

類似 Evernote 的跨平台筆記 App：**離線優先、Google 帳號登入即同步**。

- **主程式（PWA）**：https://fuhu-note.web.app
- **手機下載中心**：https://fuhu-note.web.app/download/
- **下載檔案**：請至右側 **Releases** 頁面取得（安卓 APK 與 Windows 一鍵安裝版）

## 特色

- 筆記、筆記本、標籤、搜尋、垃圾桶
- 離線可完整編輯，恢復連線自動同步
- 電腦（Windows 安裝版 / 瀏覽器）與安卓手機（APK / PWA）登入同一 Google 帳號即同步
- 每則筆記變更即時同步至 Firebase（Firestore，依使用者隔離）
